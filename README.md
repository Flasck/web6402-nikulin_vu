## Лабораторная работа №2

### Тема: «Космический архив: Солнечная система»

Статический веб-сайт, посвящённый базовым астрономическим характеристикам Солнечной системы и ключевым исследовательским миссиям.

#### Структура проекта:
- `index.html` — главная страница: общее введение, структура системы и иллюстрация;
- `planets.html` — страница со сравнительной таблицей характеристик планет;
- `missions.html` — хроника и описание ключевых межпланетных экспедиций;
- `about.html` — сведения о проекте и об авторе;
- `style.css` — общий файл стилей сайта;
- `images/space.png` — локальное графическое изображение.
